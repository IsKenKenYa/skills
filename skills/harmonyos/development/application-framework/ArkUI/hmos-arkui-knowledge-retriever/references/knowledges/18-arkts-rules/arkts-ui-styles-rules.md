# ArkUI 样式扩展装饰器（@Styles / @Extend / @AnimatableExtend）

## 一、@Styles vs @Extend 对比

| 维度 | `@Styles` | `@Extend`                              |
| --- | --- |----------------------------------------|
| **定义位置** | 全局 / 组件内 | **仅全局**                                |
| **是否带 `function`** | 全局必须带；组件内不能带 | 必须带 |
| **是否指定组件** | 否（通用） | 是，必须显式指定，如 `@Extend(Text)`             |
| **是否支持参数** | ❌ 不支持，编译期报错 | ✅ 支持，遵循 TS 方法传值调用；参数可为 `function`、状态变量 |
| **可封装内容** | 仅**通用属性**和**通用事件** | 额外支持组件的**私有属性、私有事件、全局方法**              |
| **方法体内逻辑分支** | ❌ 不支持 `if/else` 等逻辑组件 | ❌ 不支持 `if/else` 等逻辑组件                                     |
| **混用规则** | 单独使用 | 不能调用 `@Styles`；可调用同组件的其他 `@Extend`     |
| **优先级** | 框架优先查找组件内 `@Styles`，找不到才查全局 | —                                      |
| **访问 `this` / 状态变量** | 组件内定义时可通过 `this` 访问常量和状态变量 | 参数传入状态变量时支持响应式刷新                       |

## 二、@AnimatableExtend

### 限制条件

| 限制项 | 说明 |
| --- | --- |
| **仅支持全局定义** | 不支持组件内部定义 |
| 函数参数类型限制 | 必须为 `number` 类型，**或**实现 `AnimatableArithmetic<T>` 接口的自定义类型 |
| 函数体调用范围 | 只能调用 `@AnimatableExtend` 括号内组件的属性方法 |
