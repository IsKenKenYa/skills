### 使用方式

```typescript
// 正确：使用已验证的 sys.symbol 名
SymbolGlyph($r('sys.symbol.house'))
  .fontSize(24)
  .fontColor([Color.Blue])  // 注意：fontColor 传数组！

// 错误：凭直觉猜名字
SymbolGlyph($r('sys.symbol.home'))  // 编译失败！home 不存在，用 house

// 搜索图标用 magnifyingglass 不是 search
SymbolGlyph($r('sys.symbol.magnifyingglass'))

// 设置图标用 gearshape 不是 settings
SymbolGlyph($r('sys.symbol.gearshape'))
```
