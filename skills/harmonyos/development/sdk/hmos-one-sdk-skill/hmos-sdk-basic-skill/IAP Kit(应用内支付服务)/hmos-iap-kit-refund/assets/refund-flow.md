# IAP Kit退款流程说明

## 退款流程概述

IAP Kit退款功能为应用内支付提供了完整的退款解决方案。退款流程包括用户申请、开发者审核、华为操作三个主要环节。

## 流程图

```
用户发起退款
    ↓
应用调用createRefundRequest
    ↓
拉起退款界面
    ↓
用户填写退款信息并提交
    ↓
开发者审核(非游戏应用)
    ├─ 同意退款 → 华为操作退款 → 退款成功
    ├─ 驳回退款 → 申请已拒绝
    └─ 超期未处理 → 华为运营审核
```

## 详细流程步骤

### 1. 用户发起退款

用户在应用内选择需要退款的订单,点击"申请退款"按钮。

**前提条件**:
- 用户已购买应用内商品
- 应用已集成IAP Kit
- 设备类型为Phone/Tablet/2in1
- 用户系统版本不低于6.16.10
- 用户已登录华为账号

### 2. 应用调用API

应用调用`createRefundRequest` API拉起退款界面:

```typescript
iap.createRefundRequest(context, purchaseOrderId).then(() => {
  // 退款申请已提交
}).catch((err: BusinessError) => {
  // 处理错误
});
```

**参数说明**:
- `context`: UIAbilityContext上下文对象
- `purchaseOrderId`: 购买订单号ID,最大长度256字符

### 3. 拉起退款界面

IAP Kit拉起退款界面,用户可以:
- 选择退款原因
- 填写退款说明
- 提交退款申请

### 4. 开发者审核(非游戏应用)

对于非游戏类应用,开发者需要在AppGallery Connect审核退款订单:

**审核流程**:
1. 登录AppGallery Connect
2. 选择应用
3. 进入"运营 > 产品运营 > 退款管理"
4. 查看用户退款申请
5. 审核退款订单:
   - **同意退款**: 输入退款金额,点击同意
   - **驳回退款**: 输入驳回原因,点击确认

**审核时限**: 开发者需在规定时间内审核,超期未处理将由华为运营审核。

### 5. 华为操作退款

开发者同意退款后,华为执行退款操作:
- 退款金额退回至用户支付账户
- 更新订单状态为"退款成功"

## 退款订单状态

| 状态 | 说明 |
|------|------|
| 申请已拒绝 | 开发者驳回退款订单 |
| 申请已通过 | 开发者同意退款订单 |
| 退款成功 | 开发者同意退款,华为操作成功 |
| 退款失败 | 开发者同意退款,华为操作失败 |
| 超期未处理 | 开发者未按时处理,华为运营审核 |

## 时间节点

- **退款申请提交**: 实时
- **开发者审核**: 1-3个工作日(建议)
- **华为操作退款**: 3-5个工作日
- **整体流程**: 约7个工作日

## 注意事项

1. **仅支持非游戏应用**: 游戏类应用退款由华为游戏运营审核,开发者无需处理
2. **退款只能由用户发起**: 开发者无法主动退款用户订单
3. **购买订单号必填**: 必须传入正确的purchaseOrderId
4. **设备限制**: 仅在Phone/Tablet/2in1设备上支持
5. **网络依赖**: 退款申请需要网络连接
6. **退款时限**: 商品消耗后可能无法退款

## 用户查看退款进度

用户可通过以下路径查看退款进度:
- 系统设置 > 华为账号 > 付款与账单 > 退款记录

## 开发者查看退款订单

开发者可在AppGallery Connect查看所有退款订单:
- 登录AppGallery Connect
- 选择应用
- 进入"运营 > 产品运营 > 退款管理"
- 查看"已完成"页签

## 错误处理

### 常见错误码

| 错误码 | 说明 | 处理方法 |
|-------|------|---------|
| 401 | 参数错误 | 检查purchaseOrderId有效性 |
| 801 | 设备不支持 | 引导用户使用支持设备 |
| 1001860000 | 用户取消 | 正常处理,无需特殊操作 |
| 1001860005 | 网络异常 | 引导用户检查网络 |
| 1001860061 | 已退款 | 提示用户订单已退款 |
| 1001860062 | 不允许退款 | 检查订单退款条件 |

## 降级方案

当应用内退款失败时,可引导用户通过以下方式退款:
- 系统设置 > 华为账号 > 付款与账单 > 购买记录
- 选择订单 > 对订单有疑问 > 申请退款
