# 申请实况窗正式权限技能

## 功能描述

本技能指导开发者在AppGallery Connect平台上申请实况窗（Live View Kit）正式权限，完成从调测环境到正式环境的转换。申请流程需要提供场景描述、接入方案等材料，经过华为评审验收后开通正式权限。

**核心能力**：
- 指导完成实况窗正式权限申请
- 提供场景描述填写规范
- 提供接入方案截图要求
- 提供申请前自检清单
- 说明审核流程和时效

**适用范围**：
- 实况窗业务已完成调测
- 应用月活数>=1000
- 应用已上架华为应用市场
- 设计方案符合《实况窗设计规范》

**限制条件**：
- 需要已通过调测验证
- 需要满足月活数要求
- 需要准备完整的申请材料
- 审核周期约7-15个工作日

**典型场景**：
- 打车出行应用需要上线实况窗功能
- 外卖配送应用需要展示配送进度
- 航班高铁应用需要展示行程信息

## 使用场景

### 触发词
- "申请实况窗正式权限"
- "开通实况窗正式权限"
- "实况窗权限申请"
- "实况窗上线申请"
- "Live View Kit正式权限"
- "实况窗调测转正式"

### 能做
- 指导在AppGallery Connect平台完成权限申请操作
- 提供场景描述的标准填写模板
- 提供接入方案截图的制作要求
- 提供申请前的完整自检清单
- 说明审核流程和预期时间
- 提供审核不通过的常见原因和解决方案

### 绝不做
- 不代替开发者在AGC平台执行实际操作
- 不修改实况窗代码实现
- 不处理实况窗调测环境配置
- 不负责与华为客服的沟通协调
- 不保证审核一定通过

### 补充
- 本技能仅适用于正式权限申请流程，不适用于调测权限申请
- 审核结果以华为官方通知为准
- 如审核不通过，需根据反馈意见修改后重新提交
- 申请过程中遇到问题可联系华为开发者支持

## 调用规范和规则

### 输入约束
- **应用信息**：应用名称、包名、项目ID
- **月活数据**：应用月活数>=1000
- **上架状态**：应用已在华为应用市场上线
- **调测状态**：已完成实况窗功能调测
- **设计规范**：符合《实况窗设计规范》要求
- **材料准备**：
  - 场景描述文本（不少于50字）
  - 接入方案截图（PNG/JPG格式，<3MB）
  - 特殊场景说明（如涉及小程序）

### 执行约束
- **操作耗时**：申请填写约15-30分钟
- **审核周期**：7-15个工作日
- **申请频次**：同一场景审核不通过后需修改再提交
- **并发限制**：同一应用同一时间只能有一个审核中的申请

### 内容约束
- **禁止内容**：
  - 虚假场景描述
  - 未经调试验证的设计方案
  - 不符合设计规范的截图
  - 涉及用户隐私的敏感信息
  - 营销广告类内容

- **必填内容**：
  - 接入场景描述
  - 消息展示时机说明
  - 展示节点列表
  - 接入方案截图（含每个状态节点）
  - 自检结果确认

### 降级约束
- **材料不完整**：提示用户补充缺失材料，提供材料清单
- **月活不达标**：建议先提升应用月活，暂缓申请
- **设计不规范**：指出不符合规范的具体项，提供修改建议
- **审核不通过**：分析审核意见，提供修改方案

## 调用流程和步骤

### 步骤1：准备阶段（前置校验）

**前置校验**：
1. 检查应用是否已在华为应用市场上线
2. 检查应用月活数是否>=1000
3. 确认实况窗功能已在调测设备完成充分调试
4. 准备符合《实况窗设计规范》的接入方案截图
5. 确认方案已通过自检验证

**参数准备**：
```json
{
  "app_info": {
    "app_name": "应用名称",
    "package_name": "应用包名",
    "project_id": "项目ID",
    "monthly_active_users": "月活数"
  },
  "scene_description": {
    "scene_type": "打车出行",
    "scene_detail": "接入场景：用户打车后，通过实况窗通知展示接驾进展、行程进展等信息",
    "display_timing": "用户提交即时出行订单后，或预约订单开始前30分钟",
    "display_nodes": ["呼叫司机", "司机赶来", "司机到达上车点", "前往目的地", "到达目的地-待支付", "到达目的地-已支付"]
  },
  "materials": {
    "scheme_screenshot": "接入方案截图路径",
    "miniprogram_proof": "小程序沟通证明（如适用）"
  }
}
```

### 步骤2：登录AppGallery Connect平台

**操作指引**：
1. 打开浏览器，访问 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)
2. 使用华为开发者账号登录
3. 点击"开发与服务"进入项目管理

**注意事项**：
- 需要使用具有项目管理权限的账号
- 如忘记密码，可通过"忘记密码"功能重置
- 确保账号已实名认证

### 步骤3：选择项目和应用的导航路径

**操作步骤**：
1. 在项目列表中找到需要开通实况窗的项目
2. 点击项目进入项目详情页
3. 导航路径：增长 > 推送服务 > 配置
4. 选择需要开通实况窗的应用
5. 找到"实况窗"选项，点击"申请"

**界面示意**：
```
项目列表
  └─ 选择项目
      └─ 增长（左侧菜单）
          └─ 推送服务
              └─ 配置（页签）
                  └─ 选择应用
                      └─ 实况窗 > 申请
```

### 步骤4：填写申请信息

**场景描述填写要求**：

需包含以下内容：
- 接入场景的描述
- 消息的展示时机基本说明
- 展示的主要节点

**示例模板**：
```
接入场景：用户打车后，通过实况窗通知展示接驾进展、行程进展等信息

展示时机：用户提交即时出行订单后，或预约订单开始前30分钟

展示节点：呼叫司机、司机赶来、司机到达上车点、前往目的地、到达目的地-待支付、到达目的地-已支付
```

**接入方案要求**：
- 图片格式：PNG或JPG
- 图片大小：不超过3MB
- 图片内容：
  - 每个状态节点的卡片效果
  - 胶囊效果
  - 锁屏效果
  - 展示时机说明
  - 主要特殊场景方案

### 步骤5：完成自检项确认

**自检清单**：
```
[ ] 确认上传的截图满足实况窗设计规范要求
[ ] 每个创建的实况窗活动均已添加结束事件
[ ] 确认实况窗与应用内任务进度与信息一致
[ ] 确认同一实时任务不存在多个实况窗
[ ] 确认已考虑并提供主要特殊场景的方案
[ ] 已经完成实况窗场景测试，满足上线要求
[ ] 认可实况窗的管理规范，若出现不符合设计规范或者违背场景准入要求，同意华为对相关场景权限进行收回
```

**检查要点**：
- 截图必须包含所有状态节点
- 每个实况窗必须有结束事件
- 任务进度与实况窗信息必须同步
- 避免重复实况窗问题
- 特殊场景（如取消订单）的处理方案

### 步骤6：提交申请并等待审核

**提交操作**：
1. 确认所有信息填写完整
2. 检查附件材料是否上传
3. 勾选自检项确认
4. 点击"提交"按钮

**审核流程**：
```
提交申请
  ↓
方案评审阶段（约7个工作日）
  ↓
评审通过 → 测试验收阶段（约8个工作日）
  ↓        ↘
  ↓         评审不通过 → 根据意见修改 → 重新提交
  ↓
验收通过 → 开通正式权限
  ↓
通知开发者（平台通知+邮件）
```

**审核时效**：
- 方案评审：约7个工作日
- 测试验收：约8个工作日（需配合）
- 总周期：约15个工作日
- 结果通知：AppGallery Connect平台消息+邮件

### 步骤7：处理审核结果

**审核通过**：
- 收到平台通知和邮件
- 实况窗权限自动开通
- 可开始正式环境部署

**审核不通过**：
- 查看审核意见（平台消息或邮件）
- 分析不通过原因
- 根据意见修改方案
- 重新准备材料
- 再次提交申请

**常见不通过原因**：
- 场景描述不清晰或不完整
- 接入方案截图不符合设计规范
- 缺少关键节点展示
- 特殊场景处理方案缺失
- 月活数据不达标
- 存在隐私或安全问题

## 错误码说明

| 错误码 | 说明 | 解决方法 |
|-------|------|---------|
| PERMISSION_DENIED | 无项目管理权限 | 联系项目管理员添加权限或使用有权限的账号 |
| APP_NOT_PUBLISHED | 应用未上架 | 先完成应用上架流程再申请权限 |
| INSUFFICIENT_MAU | 月活数不足1000 | 提升应用月活后再申请 |
| SCENE_DESC_INCOMPLETE | 场景描述不完整 | 补充完整的场景描述、展示时机、节点信息 |
| SCHEME_INVALID | 接入方案不符合规范 | 参考《实况窗设计规范》修改方案 |
| SCREENSHOT_MISSING | 缺少状态节点截图 | 补充所有状态节点的卡片、胶囊、锁屏截图 |
| SCREENSHOT_OVERSIZE | 截图文件超过3MB | 压缩图片文件大小 |
| SELF_CHECK_FAILED | 自检项未完成 | 完成所有自检项并勾选确认 |
| MINIPROGRAM_PROOF_MISSING | 小程序场景缺少证明 | 提交小程序客户端沟通对齐证明和策略变更预案 |
| AUDIT_FAILED | 审核不通过 | 查看审核意见，修改后重新提交 |

## 编译和修复问题

本技能不涉及代码编译，主要涉及材料准备和平台操作。

### 材料准备要求

**场景描述要求**：
```markdown
接入场景：[清晰描述应用场景]
展示时机：[说明实况窗出现和消失的时机]
展示节点：[列出所有状态节点，用逗号分隔]
```

**接入方案截图要求**：
- 格式：PNG或JPG
- 大小：单个文件不超过3MB
- 内容：每个状态节点的卡片、胶囊、锁屏效果
- 命名：建议使用"场景名_节点名_展示形式.png"

**小程序场景额外要求**：
如应用内支持其他应用的小程序，需提供：
1. 小程序客户端沟通对齐证明
2. 策略变更预案
3. 针对每个场景和小程序一对一制定

**问题1：找不到实况窗申请入口**
```
解决方案：
1. 确认应用已创建项目
2. 确认已在"推送服务 > 配置"页面
3. 确认应用已添加到项目中
4. 如仍找不到，联系华为开发者支持
```

**问题2：月活数显示不正确**
```
解决方案：
1. 月活数据有延迟，等待1-2天更新
2. 确认统计周期是否正确
3. 如数据有误，联系华为技术支持核实
```

**问题3：截图上传失败**
```
解决方案：
1. 检查文件格式是否为PNG/JPG
2. 检查文件大小是否超过3MB
3. 检查网络连接是否正常
4. 尝试更换浏览器或清除缓存
```

## 常见问题与解决方法

### Q1：应用月活数刚好接近1000，能否申请？
**原因**：月活数要求是硬性指标，必须>=1000
**解决方法**：
- 等待月活数稳定超过1000后再申请
- 通过运营活动提升月活数
- 确认统计数据的准确性

### Q2：调测权限和正式权限有什么区别？
**原因**：两种权限的使用范围和限制不同
**解决方法**：
- 调测权限：仅限调测设备使用，有设备数量限制
- 正式权限：面向所有用户，无设备数量限制
- 申请正式权限前必须完成调试验证

### Q3：审核周期为什么会超过15个工作日？
**原因**：审核周期受多种因素影响
**解决方法**：
- 方案评审阶段需验证设计规范符合度
- 测试验收阶段需要开发者配合提供验收版本
- 特殊场景或复杂方案需要更多评审时间
- 如超时未收到通知，可联系华为开发者支持查询进度

### Q4：审核不通过后多久可以重新申请？
**原因**：需要根据审核意见修改方案
**解决方法**：
- 审核不通过后可立即修改方案
- 修改完成后可重新提交申请
- 无需等待特定时间间隔
- 建议根据审核意见充分修改后再提交

### Q5：多个场景是否需要分别申请？
**原因**：不同场景有不同的设计要求和审核标准
**解决方法**：
- 每个场景需单独申请
- 场景申请可并行处理
- 每个场景需提供独立的接入方案截图
- 通过后每个场景独立管理权限

### Q6：申请通过后如何开始使用正式权限？
**原因**：权限开通后需要更新应用配置
**解决方法**：
- 收到审核通过通知后，权限自动开通
- 在应用代码中将调测配置切换为正式配置
- 去除调测设备限制逻辑
- 发布新版本应用到应用市场
- 正式环境开始对用户展示实况窗
