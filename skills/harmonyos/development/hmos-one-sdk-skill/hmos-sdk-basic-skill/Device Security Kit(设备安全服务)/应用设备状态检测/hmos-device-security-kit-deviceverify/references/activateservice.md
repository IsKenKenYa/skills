# 开通Device Security服务
在开通Device Security服务前，请先参考“ [应用开发准备](D:/code/APIDevice/output/md_output/harmonyos-guides/应用开发准备/应用开发准备/application-dev-overview.md) ”完成基本准备工作，再继续进行以下开发活动。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8e/v3/X7JQtr8nSvyUx9Sty3oKZw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=E665D9C130AE3A629AD80717CFFC24FCDD405E4B511C437EFE0F171C64DEEC5C)
Device Security包括应用设备状态检测、安全检测、可信应用服务、业务风险检测能力、数字盾服务，开发者请根据实际使用场景，选择开启某个或者多个能力开关。
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择开发与服务。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/yFk3TreeSbSjlVFRsSHaTw/zh-cn_image_0000002628701090.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=90353404BFB3C6405126A09287B21F92346E767B58AFD38077BB97E0FC4E0C8F)
2.
在项目列表中找到需要开通Device Security服务的项目。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6b/v3/MYWldGTjR4K9vNW2ta70YA/zh-cn_image_0000002659100317.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=6E769523200E0F7C5C529914129E5A82073826326F89A6F8A215FA1F287A64D3)
3.
选择“开放能力管理”Tab页，找到需要使用的功能，点击左侧的按钮，开通相应的功能。
-
**应用设备状态检测** ：勾选“应用设备状态检测”并点击“保存”，接入“应用设备状态检测”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9/v3/7Q3-lAkRRciP0k9odHIe7g/zh-cn_image_0000002628860968.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=C99F2E89A3242A21498062BEA8E3A114359004C99BFE7AD1E855A2D782C8D9A4)
-
**安全检测** ：勾选“安全检测服务”并点击“保存”，接入“安全检测服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bb/v3/bmJyfAf6SSG9_qYR2a7CYw/zh-cn_image_0000002659220283.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=34C3ECEF8ED1C1C7931AAE10A4B916EDEB9E12822E7C54ABC6308A562F29D9BB)
-
**可信应用服务** ：勾选“可信应用服务”并点击“保存”，接入“可信应用服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/GF7aZgxjROCRuMdn1yGs5w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=7A3367F61E35A1DBBC23918C0592D512660BCA9F3A95300E1EF2788C2E9404D8)
开通“可信应用服务”需要先申请进入允许清单，请将Developer ID、公司名称、应用名称、申请使用的服务和使用该服务的场景，发送到agconnect@huawei.com。AGC运营将审核相关材料，通过后将为您配置受限开放服务使用的名单，审核周期为1-3个工作日，请耐心等待。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/BpyS2pfESnmbe2OE1sj7GQ/zh-cn_image_0000002628701092.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=D8C1D2B3E6F47CB1E6DDC63B62AA037A47EA59490CF22ADED71DD8F76E944614)
-
**业务风险检测-涉诈剧本检测** ：点击“涉诈剧本检测”右侧申请按钮，接入“涉诈剧本检测”，审核通过后勾选对应服务并点击“保存”该服务配置。
① 在申请“涉诈剧本检测”前，需要在 [华为开发者联盟](https://developer.huawei.com/consumer/cn/) 网站上注册成为开发者，并完成 [企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489) 。
② 点击“涉诈剧本检测”右侧申请按钮，接入“涉诈剧本检测”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e5/v3/WXnv6-G5QVeALDPn-yLHYQ/zh-cn_image_0000002659100319.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=C3D3EE38770DC0F689A474F1D2EB7629B5BE1E8DC3A9CC6EF98B2644CB70E622)
③ 参考“申请原因”中的模板，提供申请必需的相关信息，包含Developer ID、公司名称、应用名称、使用场景、使用该服务的合法基础（应用使用该服务时需在其隐私声明中进行个人数据声明及用途说明，详细参考 [个人数据处理说明](D:/code/APIDevice/output/md_output/harmonyos-guides/系统/安全/Device Security Kit（设备安全服务）/个人数据处理说明/devicesecurity-personal-data.md) ，并将合法基础的相关证明上传至申请附件），然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f/v3/baPfqBbPRK6mbcF_d7yZjg/zh-cn_image_0000002628860970.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=E6A4C957FFE21E7827199F90B090ECF84883282000896AE8E9F4078DBEAB4FB7)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ff/v3/9xKfREdLT3mIiQxPjGGTbg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=B594FBF3201BE8707AED91204C5912AA1D1D508D4DC828C8C04BEA5550297636)
提交申请后，AGC运营将审核相关材料，通过后则可保存对应的服务配置，审核周期为1-3个工作日，请耐心等待。
-
**数字盾服务** ：申请本服务前，需于 [华为开发者联盟](https://developer.huawei.com/consumer/cn/) 完成 [企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489) 。认证通过后，您将在“开放能力管理”界面中查找到相应服务入口。
① 点击“数字盾服务”右侧申请按钮，接入“数字盾服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/11/v3/-N2f-w6QQjiT7k2cBkTrpw/zh-cn_image_0000002659220285.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=765BFA3A338DD1A98394B740C6AF2EF44D7FC44E7D547DE2F81CE8E1A3616EC3)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/60/v3/0rVMJo9GST6VnpRbfK0ePw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=CF1C741A6F8971849FFB3530BD34ED0B89FF9FF42A1CA50BF27B7C45828B9153)
请您在申请框填写“数字盾服务”申请原因和应用场景。AGC运营将审核相关材料，通过后则可保存对应的服务配置，审核周期为1-3个工作日，请耐心等待。
② 审核通过后勾选对应服务并点击“保存”该服务配置。
-
**星盾机密风控引擎** ​：在申请“星盾机密风控引擎”前，需要在 [华为开发者联盟](https://developer.huawei.com/consumer/cn/) 网站上注册成为开发者，并完成 [企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489) 。
① 点击“星盾机密风控引擎”右侧申请按钮，接入“星盾机密风控引擎”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/9RYd-kQLQSiTert0kYA5qA/zh-cn_image_0000002628701094.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=B119A1F78C47E074B71DB198D7805F13708D9F4C0DD1F802439FF4968ED9CAF9)
② 参考“申请原因”中的模板，提供申请必需的相关信息，包含公司名称、应用用户规模、使用场景及用途，然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c5/v3/tprULRhbR9WzeZUf5Dd6LA/zh-cn_image_0000002659100321.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=E3B5B1D8B5B75DA21E00583523184F0302730AC1353A9B24BE757738BC895F61)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/90/v3/az4odRXER0C3iNfiHoOmqw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260701T104809Z&HW-CC-Expire=86400&HW-CC-Sign=EB6B78D1FFBDA106FC59D0C248ACCAC6E7128689D2692B340750117898D33BB1)
提交申请后，AGC运营将审核相关材料，通过后则可保存对应的服务配置，审核周期为1-3个工作日，请耐心等待。
4.
申请Profile（.p7b）文件，具体操作请参见 [申请调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-profile-0000002248181278) 。
