# 平台类合单服务端最小结构示例

## 适用前提

- 用户已确认自己是平台类商户。
- 已明确主单与子订单关系。
- 已具备平台类合单接口所需的商户配置和证书。

## 结构示意

```ts
app.post('/payment/combine/prepay', async (req, res) => {
  const combineRequest = buildCombinePrepayRequest(req.body);
  const combineResponse = await callHuaweiCombinePrepayApi(combineRequest);
  const orderStr = buildOrderStrFromCombineResponse(combineResponse);

  res.json({
    orderStr,
    combineOutTradeNo: combineRequest.combineOutTradeNo
  });
});
```

## 关键点

- 重点不在客户端拉起，而在服务端正确组织合单主单、子订单和平台商户信息。
- 回调处理时要把合单结果准确映射回子订单状态。
- 若子订单模型未明确，不应直接给出看似可运行的具体代码。
