# 客户端配置示例

## 适用场景

- 用户问 `app.json5`、`module.json5` 应该怎么配。
- 用户遇到 `appId`、`client_id`、`bundleName` 相关接入问题。
- 用户遇到 权限配置，例如HTTP请求怎么接入对应 `ohos.permission` 权限问题。
- 用户遇到ASCF框架层面配置问题。

## AppScope/app.json5

```json5
{
  "app": {
    "bundleName": "com.huawei.hms.payment.demo",
    "vendor": "example",
    "versionCode": 1000000,
    "versionName": "1.0.0",
    "icon": "$media:app_icon",
    "label": "$string:app_name"
  }
}
```

## entry/src/main/module.json5

```json5
{
  "module": {
    "metadata": [
      {
        "name": "app_id",
        "value": "***"
      },
      {
        "name": "client_id",
        "value": "***"
      }
    ],
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET",
        "usedScene": {
          "abilities": ["EntryAbility"],
          "when": "always"
        }
      }
    ]
  }
}
```

## ASCF 元服务工程的配置文件

ASCF 元服务工程的配置文件分属两层，两层配置文件**不得混用**：

| 层次 | 配置文件 | 主要职责 |
|---|---|---|
| HarmonyOS 原生层 | `AppScope/app.json5` | 元服务全局信息（Bundle 名、版本、图标） |
| HarmonyOS 原生层 | `entry/src/main/module.json5` | 模块能力声明（权限、Ability、页面路由） |
| ASCF 框架层 | `ascf/ascf_src/app.json` | ASCF 应用全局配置（页面列表、窗口属性） |
| ASCF 框架层 | `ascf/ascf_src/pages/[页面名].json` | ASCF 页面级配置（单页面覆盖全局配置） |
| ASCF 框架层 | `ascf/ascf_src/ascf.config.json` | ASCF 编译行为配置 |
| ASCF 框架层 | `ascf/ascf_src/ext.json` | 元服务三方平台配置，通过 `has.getExtConfig` 读取 |

## ascf/ascf_src/app.json

```json5
{
  "pages": ["page/index/index"],
  "window": {
    "navigationBarTitleText": "ascf",
    "navigationBarTextStyle": "black"
  }
}
```

## 提示

- `bundleName` 要与 AGC 中创建的应用保持一致。
- `app_id` 和 `client_id` 只做最小必要配置，不擅自扩写无关字段。
- 若用户已有文件，应基于现有内容做最小差异修改。
