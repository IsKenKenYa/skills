# 正地理编码 API

## 服务概述

将结构化地址（省/市/区/街道/门牌号）解析为对应的位置坐标。地址结构越完整，地址内容越准确，解析的坐标精度越高。

- **版本**: 1.0
- **服务标识**: `geocode`
- **官方文档**: <https://developer.huawei.com/consumer/cn/doc/harmonyos-references/map-site>

### 接口定义

**函数**: `geocode(params: GeocodeParams): Promise<GeocodeResult>`

**导入方式**:

```typescript
import { site } from '@kit.MapKit';
```

### 请求参数 (GeocodeParams)

| 参数       | 类型                                         | 是否可选 | 描述              |
|----------|--------------------------------------------|------|-----------------|
| query    | string                                     | 否    | 待解析的地址（最大512字符） |
| language | string                                     | 是    | 返回结果的语言         |
| bounds   | [LatLngBounds](common.md#latlngbounds矩形区域) | 是    | 返回结果偏向的矩形区域     |

### 响应结果 (GeocodeResult)

| 字段    | 类型                                  | 是否可选 | 描述     |
|-------|-------------------------------------|------|--------|
| sites | Array\<[Site](common.md#地点信息Site)\> | 否    | 解析结果列表 |

详细类型定义请参考 [Site类型](common.md#地点信息Site)。

### 常见问题

**Q: 地址应该怎么填写精度最高？**

A: 推荐使用完整的结构化地址信息，如"省+市+区+街道+门牌号"。地址结构越完整，解析精度越高。

**Q: 为什么有时候返回的坐标有偏差？**

A: 地址过于模糊时解析精度会降低，建议提供更完整的地址信息。

**Q: 支持哪些国家的地址解析？**

A: 华为Map Kit支持全球多个国家和地区的地址解析，具体支持范围请参考官方文档。
