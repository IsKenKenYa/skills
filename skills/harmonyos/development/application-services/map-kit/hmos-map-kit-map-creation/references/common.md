# 地图创建通用常量

## 概述

本文档列出Map Kit地图创建相关的通用常量，包括坐标系类型、错误码等。

## 坐标系类型

| 常量名                  | 值 | 说明              |
|----------------------|---|-----------------|
| CoordinateType.WGS84 | 0 | WGS84坐标系        |
| CoordinateType.GCJ02 | 1 | GCJ02坐标系（国测局坐标） |

## 覆盖物通用属性

### LatLng（坐标对象）

| 字段        | 类型     | 是否可选 | 说明 |
|-----------|--------|------|----|
| longitude | number | 否    | 经度 |
| latitude  | number | 否    | 纬度 |

### LatLngBounds（矩形区域）

| 字段        | 类型                    | 是否可选 | 说明    |
|-----------|-----------------------|------|-------|
| southwest | [LatLng](#latlng坐标对象) | 否    | 西南角坐标 |
| northeast | [LatLng](#latlng坐标对象) | 否    | 东北角坐标 |

## 颜色格式

Map Kit使用ARGB格式的颜色值：

| 格式         | 说明           | 示例             |
|------------|--------------|----------------|
| 0xAARRGGBB | ARGB格式，透明度在前 | 0xFF0000FF（红色） |
| 0xRRGGBB   | RGB格式，默认完全透明 | 0x0000FF（蓝色）   |

常用颜色：

- 红色：0xFFFF0000
- 绿色：0xFF00FF00
- 蓝色：0xFF0000FF
- 白色：0xFFFFFFFF
- 黑色：0xFF000000
- 透明：0x00000000

## 缩放级别

| 级别    | 描述      |
|-------|---------|
| 1-3   | 大洲级别    |
| 4-6   | 国家/省份级别 |
| 7-9   | 城市级别    |
| 10-13 | 街道级别    |
| 14-20 | 建筑级别    |

## 常见错误码

| 错误码 | 说明     |
|-----|--------|
| 0   | 成功     |
| 1   | 通用错误   |
| 2   | 无效参数   |
| 3   | 不支持的操作 |
| 4   | 权限不足   |
| 5   | 网络错误   |
| 6   | 超时     |

## CapStyle（线帽样式）

| 常量名             | 值 | 说明     |
|-----------------|---|--------|
| CapStyle.BUTT   | 0 | 线帽为平行线 |
| CapStyle.ROUND  | 1 | 线帽为半圆形 |
| CapStyle.SQUARE | 2 | 线帽为方形  |

## JointType（折线拐点类型）

| 常量名               | 值 | 说明   |
|-------------------|---|------|
| JointType.DEFAULT | 0 | 尖角拐点 |
| JointType.BEVEL   | 1 | 斜角拐点 |
| JointType.ROUND   | 2 | 圆角拐点 |

## PatternItem（虚线样式）

| 字段     | 类型              | 是否可选 | 说明       |
|--------|-----------------|------|----------|
| type   | PatternItemType | 否    | 边框样式类型   |
| length | number          | 是    | 虚线长度，默认1 |

## PatternItemType（虚线类型）

| 常量名                    | 值 | 说明 |
|------------------------|---|----|
| PATTERN_ITEM_TYPE_DASH | 0 | 虚线 |
| PATTERN_ITEM_TYPE_GAP  | 1 | 间隔 |
| PATTERN_ITEM_TYPE_DOT  | 2 | 点  |
