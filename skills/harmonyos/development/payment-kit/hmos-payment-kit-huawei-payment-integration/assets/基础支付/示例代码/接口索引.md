# 基础支付接口索引

> 提供代码前，先确认客户端类型和是否需要服务端示例。

## 客户端拉起支付

| 客户端类型 | 说明 | 参考资源 |
|---|---|---|
| 标准 HarmonyOS App | 使用 `paymentService.requestPayment(...)` | [标准App-客户端支付示例](标准App-客户端支付示例.md) |
| ASCF 元服务 | 使用 `has.requestPayment(...)` | [ASCF-客户端支付示例](ASCF-客户端支付示例.md) |
| 客户端配置 | `bundleName`、`app_id`、`client_id` 配置核对 | [客户端配置示例](客户端配置示例.md) |

## 服务端预下单

| 语言 | 说明 | 参考资源 |
|---|---|---|
| Java SDK | 使用 `DefaultPetalPayClient` 调用 `/api/v2/aggr/preorder/create/app` 并返回 `buildOrderStr(...)` 结果 | [Java-服务端预下单示例](Java-服务端预下单示例.md) |
| Java SDK 配置 | `petalpayconfig.properties` 的最小字段集 | [Java-服务端配置示例](Java-服务端配置示例.md) |
| 其他语言 | 先读通用签名规则，再按官方接口补最小实现 | [签名与验签规则](../../../references/4-通用规则/接入指南/签名与验签规则.md) |
