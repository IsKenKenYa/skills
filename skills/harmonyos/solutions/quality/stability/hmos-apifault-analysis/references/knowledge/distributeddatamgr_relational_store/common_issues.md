# relational_store 常见问题排查指南

> 每条问题关联错误码并引用 errorcode-data-rdb.md 处理步骤。

---

## 1. 参数问题

### 1.1 传入参数类型或取值范围不正确

- **关联错误码**: 14800001(无效参数)、401(通用参数错误)
- **排查建议**:
  1. 参考接口参数说明，检查参数取值范围、长度、格式。
  2. 确认必填参数已传入，类型匹配(如 ValueType 仅支持 null/number/string/boolean/Uint8Array/Asset/Assets/Float32Array/bigint)。
  3. 注意 limitAs/offsetAs 参数必须为非负整数。

### 1.2 SQL 语句不是查询语句

- **关联错误码**: 14800019
- **排查建议**: querySql/querySqlSync 仅接受 SELECT 查询语句，不能传入 INSERT/UPDATE/DELETE;如需执行非查询语句请使用 executeSql/execute。

### 1.3 SQL 语句语法错误

- **关联错误码**: 14800021(SQLite通用错误)
- **排查建议**: 检查表名/列名是否存在、函数是否已定义、SQL拼接是否正确。

## 2. 数据库文件/路径问题

### 2.1 数据库路径不合法

- **关联错误码**: 14800010
- **排查建议**:
  1. 检查传入的数据库路径是否合法，路径最大长度 128 字节。
  2. 确认 rootDir + customDir + name 拼接后的路径存在且有读权限。

### 2.2 数据库文件损坏

- **关联错误码**: 14800011
- **排查建议**:
  1. 在日志中搜索 "fdsan" 排查文件描述符问题。
  2. 确认未在数据库使用过程中通过文件接口直接操作数据库文件。
  3. 确认 db 文件和 wal 文件属于同一数据库。
  4. 如可接受数据丢失，删除数据库后重建;否则参考"数据库备份与恢复"文档。

### 2.3 密钥损坏或丢失

- **关联错误码**: 14800020
- **排查建议**:
  1. 检查密钥文件权限和内容是否正常。
  2. 重建数据库或通过 restore 恢复。
  3. 加密数据库创建后不可直接修改 encrypt 配置，需使用 rekeyEx 切换加密状态。

### 2.4 数据库配置变更

- **关联错误码**: 14800017
- **排查建议**:
  1. 确保 area、securityLevel、读写权限等关键配置保持不变。
  2. 如确需变更:用原配置导出数据，删除旧库，用新配置创建新库。
  3. 检查是否通过 chmod 修改了数据库文件读写权限。

## 3. SQLite 锁与并发问题

### 3.1 数据库文件已锁定(BUSY)

- **关联错误码**: 14800024
- **排查建议**:
  1. 避免多进程(UIAbility 与 DataShareExtensionAbility)同时打开同一数据库增删改。
  2. 等待一段时间后重试。
  3. 同一 group 组内不同应用进程通过 group 打开同一数据库时也可能触发。

### 3.2 数据库表被锁定(LOCKED)

- **关联错误码**: 14800025
- **排查建议**:
  1. 确保无其它进程/线程正在写操作。
  2. 事务中:beginTransaction 后 commit 前不做额外写操作。
  3. 确保数据库连接在操作完成后正确关闭。

### 3.3 数据库无响应

- **关联错误码**: 14800015
- **排查建议**:
  1. 默认超时 2s，读写/attach/detach 等操作阻塞时触发。
  2. attach/detach 可增加 waitTime 参数延长等待。
  3. 重新尝试操作。

### 3.4 WAL 文件过大

- **关联错误码**: 14800047
- **排查建议**:
  1. 检查结果集(ResultSet)和事务(Transaction)是否未关闭。
  2. 关闭所有打开的结果集和事务，使 WAL 可以 checkpoint。
  3. 避免在开启读事务或结果集未关闭时持续执行增删改操作。

## 4. 结果集/类型问题

### 4.1 结果集为空或位置不合法

- **关联错误码**: 14800012
- **排查建议**: 检查结果集是否为空或指定的行号是否在 [0, rowCount - 1] 范围内。

### 4.2 列号超出范围或类型不兼容

- **关联错误码**: 14800013
- **排查建议**:
  1. 检查列号是否在 [0, columnCount - 1] 范围内。
  2. 检查列数据类型是否与调用的 get 方法匹配(如 getString/getLong/getBlob/getDouble)。

### 4.3 类型转换失败

- **关联错误码**: 14800041
- **排查建议**: 通过 resultSet 获取数据时，确保传入字段的数据类型与使用的接口匹配。

### 4.4 查询无数据

- **关联错误码**: 14800018
- **排查建议**: 编写正确的查询语句或先添加数据后再做查询。

## 5. 实例关闭/事务问题

### 5.1 目标实例已关闭

- **关联错误码**: 14800014
- **排查建议**:
  1. RdbStore 已 close 后不可再使用，需重新 getRdbStore。
  2. ResultSet 已 close 后不可再使用，需重新 query。
  3. Transaction 已 commit/rollback 后不可再使用。

### 5.2 SQLite 库使用不正确(MISUSE)

- **关联错误码**: 14800034
- **排查建议**:
  1. 确保数据库操作之间有适当同步(锁或其它同步机制)。
  2. 确保连接在使用前打开、结束后关闭。
  3. 确保所有数据库对象使用完毕后正确释放。

## 6. 权限与 Stage 模型问题

### 6.1 非 Stage 模型

- **关联错误码**: 14801001
- **排查建议**: 切换上下文环境使用 Stage 模型(FA 模型不支持)。

### 6.2 dataGroupId 非法

- **关联错误码**: 14801002
- **排查建议**: 从应用市场正常申请 dataGroupId，并正确传入 StoreConfig.dataGroupId。

### 6.3 权限被拒绝

- **关联错误码**: 202、14800023(SQLite PERM)
- **排查建议**:
  1. 在 module.json5 中声明所需权限。
  2. 确认文件没有只读属性。
  3. 检查文件和文件夹权限。
  4. 确认没有其它进程锁定数据库文件。

---

## 7. 云/分布式问题

### 7.1 分布式表类型不匹配

- **关联错误码**: 14800051
- **排查建议**: 对同一数据库表设置的分布式类型(DistributedType)必须前后一致;端端同步的分布式表不可再设置为端云同步表。

### 7.2 获取订阅服务失败

- **关联错误码**: 14800050
- **排查建议**: 当前平台不支持订阅服务，需在平台部署订阅服务。

### 7.3 数据库别名已被使用

- **关联错误码**: 14800016
- **排查建议**: attach 时别名不能重复;修改附加数据库的别名或不进行附加操作。

### 7.4 SQLite 只读数据库写入失败

- **关联错误码**: 14800027
- **排查建议**:
  1. 确认 StoreConfig.isReadOnly 未设为 true。
  2. 确认 rootDir 打开的数据库为只读(设计如此)，写入操作需使用非 rootDir 模式。
  3. 检查文件系统是否为只读。

### 7.5 SQLite 磁盘 I/O 错误

- **关联错误码**: 14800028
- **排查建议**:
  1. 检查文件路径是否存在、权限是否正常。
  2. 检查磁盘空间是否充足。
  3. 检查文件是否损坏。

### 7.6 SQLite 数据库已满

- **关联错误码**: 14800029
- **排查建议**: 减小数据量或增加磁盘空间。

### 7.7 SQLite 无法打开数据库文件

- **关联错误码**: 14800030
- **排查建议**: 确认数据库文件路径正确、权限正常、磁盘空间充足。
