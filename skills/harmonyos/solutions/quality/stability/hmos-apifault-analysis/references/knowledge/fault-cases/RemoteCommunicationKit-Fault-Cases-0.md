# RemoteCommunication Kit 故障定位知识库

## 知识库概述

本知识库基于 RemoteCommunication Kit 故障测试 Demo 项目，提供远程通信相关错误的快速定位指南。

## 一、错误码总览

| 错误码     | 名称                             | 分类            | 关键特征                |
| ---------- | -------------------------------- | --------------- | ----------------------- |
| 1007900060 | 远程服务器SSL证书或SSH秘钥不正确 | SSL证书验证错误 | HTTPS连接时证书验证失败 |
| 1007900028 | 操作超时                         | 网络超时错误    | 连接或传输时间超过阈值  |

## 二、错误码详细定位指南

### 2.1 错误码 1007900060 - SSL证书验证错误

#### 错误描述

远程服务器SSL证书或SSH秘钥不正确

#### 触发场景

| 场景ID       | 场景名称         | 触发方法                                 | 问题定位建议                                         |
| ------------ | ---------------- | ---------------------------------------- | ---------------------------------------------------- |
| 1007900060_1 | 无效SSL证书连接  | 连接 expired.badssl.com (过期证书)       | 证书已过期，检查服务器证书有效期或联系管理员         |
| 1007900060_2 | 自签名证书连接   | 连接 self-signed.badssl.com (自签名证书) | 服务器使用自签名证书，需在设备上安装证书或确认有效性 |
| 1007900060_3 | 错误域名证书连接 | 连接 wrong.host.badssl.com (域名不匹配)  | 证书域名与请求域名不匹配，确认URL正确或更新证书      |
| 1007900060_4 | 未信任根证书连接 | 连接 untrusted-root.badssl.com           | 根证书不在系统信任存储中，检查中间证书配置           |
| 1007900060_5 | SHA-1证书连接    | 连接 sha1.badssl.com (已废弃签名)        | SHA-1已被废弃，建议服务器升级到SHA-256证书           |

#### 快速定位步骤

```
1. 确认URL是否使用HTTPS协议
2. 检查错误消息中的证书问题类型
3. 根据具体问题采取对应措施：
   - 过期证书 → 联系服务器管理员更新证书
   - 自签名证书 → 设备安装证书或使用受信任CA签发
   - 域名不匹配 → 确认请求URL或更新证书SAN配置
   - 未信任根证书 → 添加中间证书或使用知名CA
   - SHA-1证书 → 升级加密算法
```

#### 代码示例（正常HTTPS连接）

```typescript
const sess: rcp.Session = rcp.createSession();
const request: rcp.Request = new rcp.Request('https://www.baidu.com', 'GET');
const response: rcp.Response = await sess.fetch(request);
sess.close();
```

### 2.2 错误码 1007900028 - 操作超时

#### 错误描述

操作超时（连接超时或传输超时）

#### 触发场景

| 场景ID       | 场景名称     | 触发方法                        | 问题定位建议                     |
| ------------ | ------------ | ------------------------------- | -------------------------------- |
| 1007900028_1 | 连接不可达IP | 连接 10.255.255.1:9999          | 目标地址不可达，检查网络连通性   |
| 1007900028_2 | 极短超时配置 | connectMs=1, transferMs=1       | 超时配置过短，增加超时时间       |
| 1007900028_3 | 高延迟服务器 | httpbin.org/delay/10 (延迟10秒) | 服务器响应慢，增加超时或检查网络 |
| 1007900028_4 | 连接被拒绝   | www.baidu.com:9999 (端口未开放) | 端口未开放，检查端口配置         |

#### 快速定位步骤

```
1. 检查超时配置是否合理
2. 测试网络连通性（ping/dns）
3. 确认目标端口是否开放
4. 根据场景采取措施：
   - 超时配置过短 → 增加connectMs/transferMs（建议30秒以上）
   - 网络不可达 → 检查防火墙/代理设置
   - 服务器响应慢 → 增加超时时间或优化请求
   - 端口未开放 → 确认目标服务端口配置
```

#### 超时配置代码示例

```typescript
// 正常超时配置（推荐）
const sess: rcp.Session = rcp.createSession({
  requestConfiguration: {
    transfer: {
      timeout: {
        connectMs: 30000,   // 30秒连接超时
        transferMs: 30000,  // 30秒传输超时
      },
    }
  }
});
```

### 2.3 错误码 1007900035 - SSL连接错误

#### 错误描述

SSL连接错误（非证书验证问题导致的SSL握手失败）

#### 触发场景

| 场景ID       | 场景名称            | 触发方法                   | 问题定位建议                        |
| ------------ | ------------------- | -------------------------- | ----------------------------------- |
| 1007900035_1 | HTTP端口上建立HTTPS | https://www.baidu.com:80/  | 协议与端口不匹配，使用正确HTTPS端口 |
| 1007900035_2 | 弱加密套件服务器    | dh480.badssl.com (480位DH) | 加密算法过弱，升级服务器加密配置    |

#### 快速定位步骤

```
1. 确认HTTPS端口配置正确（默认443）
2. 检查是否在HTTP端口上使用HTTPS协议
3. 检查服务器加密套件配置
4. 根据场景采取措施：
   - 协议端口不匹配 → 使用正确的协议和端口组合
   - 加密算法过弱 → 升级服务器TLS配置
```

#### 协议端口正确配置示例

| 协议  | 默认端口 | 正确URL格式                                  |
| ----- | -------- | -------------------------------------------- |
| HTTP  | 80       | http://domain.com 或 http://domain.com:80    |
| HTTPS | 443      | https://domain.com 或 https://domain.com:443 |

## 四、错误捕获与处理代码模板

```typescript
import { BusinessError } from '@kit.BasicServicesKit';
import { rcp } from '@kit.RemoteCommunicationKit';

async function safeRequest(url: string): Promise<void> {
  const sess: rcp.Session = rcp.createSession();
  const request: rcp.Request = new rcp.Request(url, 'GET');

  try {
    const response: rcp.Response = await sess.fetch(request);
    console.info('请求成功: ' + response.statusCode);
  } catch (error) {
    const businessError: BusinessError = error as BusinessError;

    // 根据错误码进行定位和处理
    switch (businessError.code) {
      case 1007900060:
        console.error('SSL证书错误: ' + businessError.message);
        // 检查证书类型，建议用户确认服务器证书配置
        break;
      case 1007900028:
        console.error('操作超时: ' + businessError.message);
        // 建议增加超时时间或检查网络状况
        break;
      case 1007900035:
        console.error('SSL连接错误: ' + businessError.message);
        // 建议检查协议与端口是否匹配
        break;
      default:
        console.error('其它错误: ' + businessError.code + ' - ' + businessError.message);
    }
  } finally {
    sess.close();
  }
}
```

## 五、常见问题FAQ

### Q1: HTTPS请求总是返回1007900060怎么办？

**原因分析**：目标服务器证书存在问题
**解决方案**：

1. 检查服务器是否使用有效CA签发的证书
2. 确认 证书未过期
3. 确认 证书域名与请求域名匹配
4. 如为自签名证书，需要在设备上安装信任证书

### Q2: 如何设置合理的超时时间？

**建议值**：

- connectMs: 30000 (30秒) - 用于建立连接
- transferMs: 30000 (30秒) - 用于数据传输
- 根据业务场景调整：API调用可缩短，文件下载需延长

### Q3: HTTP和HTTPS端口能否混用？

**不能混用**：

- HTTP端口(80)不支持SSL握手
- HTTPS端口(443)需要SSL加密
- 强制混用会导致1007900035错误
